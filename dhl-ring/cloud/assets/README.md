# Board background

Drop an image called `background.jpg` in this folder, commit, and push — the
public board at `/board` will use it automatically on every screen.

- Landscape, at least 1920x1080. The tower sits in the middle, so keep the
  centre of the image reasonably calm.
- Keep it under ~500 KB. It is downloaded by every viewer.
- A dark image works best; a radial scrim is applied on top for legibility,
  but it cannot rescue a bright, busy photo.

Other ways to set a background, no commit needed:

- `?bg=https://example.com/photo.jpg` — per-screen, wins over this file.
- The ▣ button on the board — picks an image from the machine you are on and
  remembers it in that browser only. Good for the booth screen. `⌫` clears it.
